  # WorkBench
  
  ### Description
  Workbench is a dedicated fitness companion app that allows users to track the details of their workouts. Users can log information from their workouts, allowing them to track their progress, improvemennt, and consistency over time.
  
  ### Problem it Solves
  It's hard to keep track of how your workout went if you're not writing them down. It's even harder to track progress numerically without wriitng down this kind of informaition. By providing a digital way to do this, it's so much easier to keep track of your gym growth. Also showing the number of times a user attneded a gym recently can be motivation to most to go.
  ### Tech Stack
  - Frontend: React
  - Backend: ASP.NET Core
  - DATABASE: MySQL
    
  ### Features
  - Log workouts by date and muscle focus
  - Track exercises, sets, weight, and reps
  - View and edit past workouts
  - See volume and intensity stats per session

## Instructions

## Installation
``` bash


#Clone into repo and make working directory
git clone
cd mern-group4

#Install dependencies
npm install
```
## Usage
``` bash


#Activate the backend
cd backend/
dotnet watch

#Activate the frontend
cd ../frontend
npm run dev 
```
